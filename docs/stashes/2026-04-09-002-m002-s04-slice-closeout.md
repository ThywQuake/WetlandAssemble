## 这一层建立的关键模式

1. **不要再猜文件名。** 后续代码应该通过 semantic reload helper 按 `region_id / participant_ids / ledger_key` 重开。
2. **不要把三条线压成一个假共享分数。** ledger 保留 `primary_score_name` / `primary_score_value` / `family_percentile` / `line_specific_json`，只提供统一 analysis object，不伪造数值可比性。
3. **共享 evidence object 必须 fail closed。** manifest + CSV 只要缺一半、metadata 不匹配、SHA 不对、region 混了，就必须拒绝复用。
4. **planner 路径过期时，以 artifact semantics 为准。** 当前 snapshot 没有 `percentage_hotspots.py` / `classification_contract.py` 这两个 planner 里写的来源模块，真正可靠的 source of truth 是 evidence-contract family 本身。
