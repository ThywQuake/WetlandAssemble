# S03 Route Audit & Risk Register

This artifact is the canonical route judgment for S03. It separates the **current recommended continuation path**, the **supporting but non-primary route(s)**, and the **historical/stale or misleading route family** so later work does not have to reconstruct Phase 4 truth from conflicting plans and stash notes.

## Evidence Rule

When older still-`active` plans disagree with newer implementation history, use the following evidence order:

1. `.gsd/milestones/M001/slices/S02/S02-PHASE-MODULE-MATRIX.md`
2. current source code in `src/WA/comparison/phase4_regional.py`, `src/WA/comparison/trends.py`, `scripts/build_phase4_gwd30_pixel_stats.py`, `scripts/submit_phase4_gwd30_pixel_stats.sh`, `scripts/run_phase4_regional.py`, and `scripts/hpc_probe_trends.py`
3. 2026-04-06 route-reset evidence in `docs/stashes/2026-04-06-003-phase4-conversation-summary.md`, `docs/stashes/2026-04-06-005-phase4-stage2-pixel-stats-regional-integration.md`, `docs/stashes/2026-04-06-007-phase4-berkeley-mask-bbox-oom-fix.md`, `docs/stashes/2026-04-06-008-phase4-recall-entry.md`, and `CHANGELOG.md`
4. older 2026-04-05 route notes and plans such as `docs/stashes/2026-04-05-007-phase41-gwd30-manifest-list-hpc-sharding.md`, `docs/stashes/2026-04-05-009-phase41-gwd30-pixel-reduce-then-mask-merge.md`, `docs/plans/2026-04-05-phase41-gwd30-full-period-stage-optimization-plan.md`, and `docs/plans/2026-03-23-feat-phase4-trend-analysis-implementation-plan.md`

In other words: newer source-code-backed 2026-04-06 evidence overrides older route language when they conflict.

### Canonical live chain

1. Run Stage 1 through `scripts/build_phase4_gwd30_pixel_stats.py` directly or via `scripts/submit_phase4_gwd30_pixel_stats.sh`.
2. Feed those Stage-1 manifests into `scripts/run_phase4_regional.py`.
3. Treat the resulting output as the current implemented Phase 4 continuation for regional tables.

**Important boundary:** this current route does **not** imply that a broad batch runner named `scripts/run_phase4_trend_analysis.py` exists. In this worktree that file is absent, so the current mainline should be read as **Stage 1 pixel stats -> Stage 2 regional tables**, not as “the full region-targeted trend-analysis story is already wired.”
