This artifact converts S01's frozen inventory into an evidence-graded matrix. T01 established the grading contract and the early/core phase rows; T02 extends the late-phase continuation rows and makes the Phase 4 current-vs-historical split explicit. Later S02 tasks add the module-family rows.

## Grading Contract

- This matrix uses D002's exact evidence grades: `validated`, `implemented-but-unverified`, `historical/stale path`, and `unclear`.
- Canonical raw-evidence inputs come from [S01-INVENTORY.md](../S01/S01-INVENTORY.md) and [S01-DRIFT-BOUNDARIES.md](../S01/S01-DRIFT-BOUNDARIES.md). S01 freezes what is locally inspectable; this matrix adds grade judgments on top of that freeze.
- Proof must stay split by surface:
  - **Local evidence** = code, tests, changelog, stash notes, and other files directly readable in this worktree.
  - **HPC / external proof** = recorded HPC probe results, ignored `results/` outputs, `/lustre/...` data roots, Earth Engine behavior, and any rerun that cannot be re-proven from this worktree alone.
- Do **not** upgrade a row to `validated` just because code/tests/docs exist locally. If fresh runtime or HPC confirmation is missing, keep the row at `implemented-but-unverified`.
- When older plan text disagrees with newer implementation history, weight the newer `CHANGELOG.md` entries and terminal stash summaries above stale `active` plans. This follows the route-drift weighting already frozen in [S01-DRIFT-BOUNDARIES.md](../S01/S01-DRIFT-BOUNDARIES.md).
- `historical/stale path` is reserved for routes or surfaces that later evidence explicitly superseded; `unclear` is reserved for surfaces whose current state cannot be defended even at the local-doc level.
